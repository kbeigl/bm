= GTS Real Time Service

After developing several independent components we can compile them together 
to a Real Time Service for Traccar, the `traccar-realtime-service`.
The Service wraps the `traccar-realtime-client` - 
to control the server with the `traccar-api-client` 
and to monitor the server with the RealTime WebSocket connection -
and all GPS Trackers, virtual or real, into a single layer.
This `traccar-realtime-service` is a Java Client Software, 
which can be used to control and interact via live surveillance 
with your Traccar Server Scenario, like a vehicle fleet.
