= The Traccar Real Time Client

The `traccar-realtime-client` is a Java Client Software to provide control over your Traccar Server. 
The REST API can be accessed by your software via the `traccar-api-client` or with a Java Interface. +
You can _create_ a complete Scenario, including devices, geofences, users and other entities. +
And you can _observe_, predict and react to live events - defined by your business -
via live surveillance of your Traccar Server Scenario. 
For example you can control the timing for a _rendez vous_ point for logistic vehicles.
