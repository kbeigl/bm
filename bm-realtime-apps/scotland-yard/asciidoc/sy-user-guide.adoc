= Scotland Yard Users Guide

Note that this real time scenario is a proof of concept for a real time application. +
It does not cover all the rules of the board game.
The rules are reduced to a minimum as a reachable goal 
for a first (but extendable) implementation of a real time scenario.
No Taxi, no Bus, no Underground, no black tickets - *no tickets at all*.
No barriers.


== Game Description

On a map of London, one player - alias Mister X - moves invisibly along the stations.
After Mr. X has made his move, the other players - Scotland Yard detectives - are allowed to make their move. 
The goal is to move to the field where Mister X is located. 
Mister X only shows his position every x moves, otherwise he is invisible.
Detectives can and should communicate their strategies to catch Mister X.
